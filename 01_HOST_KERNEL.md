• What it is: The foundational, read-only layer of the operating system that directly interfaces with bare-metal hardware.
• Technologies inside: Immutable Linux distribution base (e.g., ostree-based architecture), systemd-sysext for dynamic non-intrusive extension loading, and low-level NPU/GPU drivers (Qualcomm Snapdragon NPU SDK / NVIDIA CUDA Toolkit).
• Purpose: To provide a rock-solid, completely hardened, and unmodifiable host environment that securely schedules compute resources for the AI core and hardware accelerators, while remaining entirely insulated from modifications generated by the agentic layers.
